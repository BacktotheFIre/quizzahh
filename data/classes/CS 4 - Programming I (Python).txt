Q: What does print(2 ** 3 ** 2) display?

- 64
* 512
- 36
- 729
Why: ** (power) groups from right to left, so it means 2 ** (3 ** 2), which is 2 to the 9th, or 512. Most other operators go left to right. When in doubt, add parentheses.

Q: What happens when you run s = "cat" and then s[0] = "b"?

Q: What is printed?

Q: What is the difference between nums.append([4, 5]) and nums.extend([4, 5]) when nums = [1, 2, 3]?
Topic: Lists
- extend adds the list as one item, giving [1, 2, 3, [4, 5]]; append adds each item, giving [1, 2, 3, 4, 5]
* append adds the whole list as one item: [1, 2, 3, [4, 5]]; extend adds each item: [1, 2, 3, 4, 5]
- They do the same thing, but extend returns the new list while append returns None
- append makes a new list and leaves nums unchanged; extend changes nums in place
Why: append always adds exactly one element, even if that element is a list. extend loops over its argument and adds each element.

Q: Which loop runs forever?
Topic: Loops

* i = 0, then while i < 10: print(i), with no line that changes i

Why: A while loop needs something inside it to eventually make the condition false. Here i stays 0, so i < 10 is always true. Forgetting to update the loop variable is a classic infinite loop bug.

Q: What error does this cause?

* UnboundLocalError: count is treated as a local variable with no value yet
- NameError: count is not defined anywhere in the program

Why: Assigning to count inside the function makes Python treat it as local, so reading it first fails. Better to pass values in and return results, rather than using the global keyword.

Q: Why is with open("data.txt") as f: the recommended way to open files?
Topic: Files & Exceptions
- It reads the whole file into memory at once, which is much faster than reading line by line
* It closes the file automatically when the block ends, even if an error happens
- It's the only way Python can open a file without needing to import the os module
- It makes a backup copy of the file before you change it
Why: with uses a context manager. Without it, you must remember to call f.close(), and an error in the middle could leave the file open.

Q: What does every recursive function need to avoid running forever?
Topic: Recursion
- A loop inside the function that counts how many times it has been called
* A base case that returns without making another recursive call
- A global variable that stops the recursion after a fixed number of calls
- At least two parameters, so one can shrink while the other stays fixed
Why: For example, factorial(n) returns 1 when n <= 1 (the base case), otherwise n * factorial(n - 1). Each call must move closer to the base case, or you get a RecursionError.

Q: What does f(4) return?
def f(n):
    if n == 0:
        return 0
    return n + f(n - 1)
Topic: Recursion
- 4
* 10
- 24
- It never stops
Why: f(4) = 4 + f(3) = 4 + 3 + f(2) = 4 + 3 + 2 + 1 + 0 = 10. It sums the numbers from n down to 0. Tracing recursive calls by hand like this is a common exam skill.

Q: Must-know: what are the results of 7 / 2, 7 // 2 and 7 % 2 in Python 3?
Topic: Must-Know Facts
* 3.5, 3 and 1
- 3, 3 and 1
- 3.5, 3.5 and 1
- 3.5, 4 and 1
Why: / always gives a float, // is floor division (rounds down), and % is the remainder. Note that -7 // 2 is -4, because it rounds toward negative infinity.

Q: Must-know: which Python types are immutable?
Topic: Must-Know Facts
* int, float, str, tuple, frozenset
- list, dict, set
- str, list, tuple, bytearray, set
- int, float, list, dict, frozenset
Why: Immutable objects can't be changed in place, so "changing" them really makes a new object. Only immutable (hashable) values can be dictionary keys or set members.

Q: Must-know: what does s[start:stop:step] include?
Topic: Must-Know Facts
* From index start up to, but not including, stop, moving by step
- From index start up to and including stop, moving by step
- step items, beginning at start and ending at stop
- Everything except the items between start and stop
Why: "abcdef"[1:4] is "bcd". Leaving parts out uses defaults, so s[::-1] reverses a string and s[:3] is the first three characters.

Q: Must-know: what does range(2, 11, 3) produce?
Topic: Must-Know Facts
* 2, 5, 8
- 2, 5, 8, 11
- 3, 6, 9
- 2, 3, 4, ..., 11
Why: range(start, stop, step) starts at start, adds step each time, and stops BEFORE reaching stop. That's why range(5) is 0 through 4.

Q: Must-know: which values are "falsy" in Python?
Topic: Must-Know Facts
* False, None, 0, 0.0, "", and empty collections like [], {}, ()
- Only False and None; empty strings and lists are truthy
- False, 0, and negative numbers like -1
- False, None, 0, "0", "False", and the string "None"
Why: Everything else is truthy, including "0" and "False" as strings, since they're non-empty. That's why if my_list: is the Pythonic way to check for an empty list.

Q: Must-know: what is the average time complexity of these Python operations: list.append(x), x in some_list, and x in some_set?
Topic: Must-Know Facts
* O(1), O(n) and O(1)
- O(1), O(1) and O(1)
- O(n), O(n) and O(log n)
- O(1), O(log n) and O(n)
Why: Lists are dynamic arrays, so searching them checks items one by one. Sets and dicts are hash tables. Changing a list to a set can turn a slow loop into a fast one.

Q: Must-know: what is the basic structure of a list comprehension?
Topic: Must-Know Facts
* [expression for item in iterable if condition]
- [for item in iterable: expression if condition]
- [expression if condition for item in iterable else None]
- (for item in iterable) => expression
Why: [x * x for x in range(10) if x % 2 == 0] builds the squares of the even numbers. The if part is optional. The same shape with {} makes a set or dict comprehension.

Q: Must-know: what is the order of the parts of a try statement in Python?
Topic: Must-Know Facts
* try, except, else, finally
- try, finally, except, else
- try, else, except, finally
- try, except, finally, else
Why: except runs if an error happened, else runs only if no error happened, and finally always runs. Only try and at least one of except or finally are required.
